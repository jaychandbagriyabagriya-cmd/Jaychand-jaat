रैखिक समीकरण युग्म के नोट्स

दो चरों वाले रैखिक समीकरण का सामान्य रूप ax + by + c = 0 होता है।

उदाहरण: x + y = 5 और x − y = 1

प्रश्न-उत्तर

प्रश्न: x + y = 5 और x − y = 1 का हल क्या है?

उत्तर: दोनों समीकरण जोड़ने पर 2x = 6, इसलिए x = 3। पहले समीकरण से y = 2।

द्विघात समीकरण के नोट्स

जिस समीकरण में चर की सबसे बड़ी घात 2 हो, उसे द्विघात समीकरण कहते हैं।

सामान्य रूप: ax² + bx + c = 0, जहाँ a ≠ 0।

प्रश्न-उत्तर

प्रश्न: x² − 5x + 6 = 0 के मूल ज्ञात करो।

हल: (x − 2)(x − 3) = 0

उत्तर: x = 2 या x = 3।

समांतर श्रेढ़ी के नोट्स

जिस श्रेढ़ी में लगातार दो पदों का अंतर समान हो, उसे समांतर श्रेढ़ी (AP) कहते हैं।

उदाहरण: 2, 5, 8, 11, 14, ...

सार्व अंतर: d = दूसरा पद − पहला पद

nवें पद का सूत्र: aₙ = a + (n − 1)d

प्रश्न-उत्तर

प्रश्न: 2, 5, 8, 11, ... का पाँचवाँ पद क्या है?

हल: a = 2, d = 3, n = 5

a₅ = 2 + (5 − 1) × 3 = 14
